# 🦈 Откуси Бабла — демонстрационный банковский сайт

Многостраничный учебный веб-проект в стилистике современного коммерческого банка. Внутри — каталог продуктов, страницы карт, кредитов, вкладов и инвестиций, справочные разделы, личный кабинет и формы взаимодействия.

> **Важно:** «Откуси Бабла» — вымышленный демонстрационный проект, а не действующая кредитная организация. Сайт не оказывает банковские или финансовые услуги. Цифры, предложения, отзывы и другие банковские сведения на страницах могут быть демонстрационными. Не вводите реальные пароли и другие конфиденциальные данные.

## ✨ Возможности

- Многостраничная структура с общей навигацией и подвалом.
- Адаптивный интерфейс для компьютеров и мобильных устройств.
- Переключение светлой и тёмной темы.
- Разделы продуктов: карты, кредиты, ипотека, вклады и инвестиции.
- Демонстрационные калькуляторы и интерактивные элементы.
- Страницы FAQ, контактов, отделений, отзывов и онлайн-консультанта.
- Страница личного кабинета и интерфейс авторизации.
- Форма регистрации с отправкой уведомления владельцу через Telegram (после настройки backend).

## 🚀 Запуск сайта

### Локально

Это статический frontend — сборка не требуется.

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта.
3. Запустите `index.html` в браузере либо используйте расширение Live Server в Visual Studio Code.

Для полноценной работы API локального открытия HTML недостаточно: backend нужно развернуть отдельно.

### Публикация frontend на GitHub Pages

1. Загрузите файлы проекта в репозиторий GitHub.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Укажите нужную ветку (обычно `main`) и папку `/ (root)`.
5. Сохраните настройки и дождитесь публикации.

Если backend размещён отдельно, укажите его базовый адрес в `assets/config.js`:

```js
window.OTKUSI_API_BASE = "https://ВАШ-ПРОЕКТ.vercel.app";
```

Если frontend и API размещены на одном домене Vercel, значение можно оставить пустым.

## 🤖 Настройка Telegram backend на Vercel

Backend нужен для отправки уведомлений о новых регистрациях в Telegram. Сам токен бота нельзя хранить в HTML, JavaScript frontend или Git-репозитории.

1. Импортируйте репозиторий в Vercel.
2. В настройках проекта Vercel откройте **Settings → Environment Variables**.
3. Добавьте две переменные:
   - `TELEGRAM_BOT_TOKEN` — токен Telegram-бота.
   - `TELEGRAM_CHAT_ID` — ID чата, куда отправлять уведомления.
4. Сохраните переменные и заново разверните проект (**Redeploy**).
5. Если frontend опубликован на GitHub Pages, укажите домен Vercel backend в `assets/config.js` и опубликуйте изменения.

API-обработчик регистрации проверяет обязательные поля и отправляет в Telegram имя, email и телефон. Пароль в Telegram не передаётся. Не используйте на демонстрационном сайте реальные личные данные.

**Безопасность:** если токен Telegram-бота когда-либо попадал в публичный репозиторий или архив, считайте его скомпрометированным: отзовите старый токен через [@BotFather](https://t.me/BotFather), создайте новый и сохраните только в переменных окружения Vercel. Удаления токена из текущей версии файла недостаточно, если он уже был опубликован в истории Git.

### Ограничения авторизации

`api/login.js` сейчас является заглушкой и возвращает статус `501`: постоянное хранилище пользователей и полноценная система входа не реализованы. Не воспринимайте личный кабинет как защищённый банковский аккаунт.

## 📌 Примечания

- Для статических страниц не нужны Node.js, npm или отдельная сборка.
- GitHub Pages не запускает серверные функции из папки `api/`; для них нужен Vercel или другой backend-хостинг.
- Секреты должны храниться только в переменных окружения backend-платформы.
- Ссылка поддержки открывает DonationAlerts в новой вкладке.
